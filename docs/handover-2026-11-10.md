## Evening: server image on GHCR (`klean-server`)

- The server ships as a Docker image built by the repo-root `Dockerfile` (user's choice over Jib, which was removed). One image: sync server + web app at `/`.
- `docker build -t klean-server:dev .` needs nothing but Docker: `-Pklean.serverOnly=true` (settings.gradle.kts) builds only `:shared` + `:backend`, so no Android SDK; the web app is built in a Node stage and packaged with `-Pklean.web=prebuilt`.
