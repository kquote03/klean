Klean, three directions

Eight screens each, with the same seeded day: Tuesday 10 November, 8:52 in the morning. Every direction uses the same navigation (Today, Plan, Track, People) and the same single Add button, so what differs is the look. Tap a screen name to open it full size; on a phone, open any screen directly.

Full-width sheets per direction: A, B, C.

Navigation, the other options

The three looks above all use navigation A: four grouped tabs, Today, Plan (Tasks and Calendar), Track (Workout, Sleep, Diet) and People. Any look works with either alternative, so this choice is separate.

B, customizable bar: Today plus three modules you pick (for example Tasks, Calendar, Workout); the rest open from Today's cards and a module sheet. Fewer taps for your favourites, two taps for everything else.

C, Today as the directory: the bar holds Today, Add and Search; every module opens from its Today card. The calmest bar, but every module is two taps from anywhere except Today.

Clutter count per screen

Counted by shared/chrome.js on the first viewport (412 by 915), outside the navigation bar. A list of rows counts once. Budget: at most 7 controls, no text inputs outside the Add menu, one primary action.
